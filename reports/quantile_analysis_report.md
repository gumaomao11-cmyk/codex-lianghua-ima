## 4. 结论

**回答"IC 反号是真市场规律还是纯噪声"这个问题：两者都不是——是第三种情况。**

1. **`factor_clean_alpha`（路线 A 主力因子）情绪方向确定为负**：四个子期全部为负、不变号
   （-13.5%/-37.4%/-21.6%/-3.8%），单调性 -0.6 ~ -0.9。它不是噪声，而是**稳定的反向指标**，
   或更准确说：LLM 打的高分捕捉的是"已经涨完/共识拥挤"的票。
2. **路线 A 此前 70% 年化的真实来源是覆盖度倾斜**，即"被星球讨论的股票"整体跑赢票池 +32% 年化。
   这是一个**票池选择效应**，不是 LLM 评分能力。而且非重叠 t 只有 1.36，并不显著。
3. **`factor_opinion_1d` 看似最好，实为静态标的名单**。无前视分解显示 21 日纯时间信号 t=0.20，
   彻底归零；全部效果来自"历史平均被看好的票"这一静态属性。
4. **`news_1d` / `event_3d` / `research_20d` 均在子期内变号**（1~2 次），单调性在 -0.7 到 +1.0 之间乱跳，
   符合"提示词漂移 + 18 模型混用"导致的测量噪声，与书 5.1.3 第一条描述一致。

**按书 3.4.7 的门禁标准，没有任何一个因子通过**：要求分位数单调 + 多空显著 + 子期不变号 + 剔除标的效应后仍存活，
现有 10 个因子中 0 个满足。

## 5. 这一步省下了什么

原计划的 P1（600 条跨期抽样，约 1.5h）+ P2（全量重抽 11,513 条，8~14h）目的是"修复测量噪声后看 IC 是否稳定"。
但 3.1 和 3.2 表明：**即使把测量噪声完全消除，情绪评分的截面方向也是负的或归零的**——
因为负向性和静态性都是在"每日 38 只、412 天"这个足够大的样本上稳定出现的，不是缺样本导致的。
所以直接投入全量重抽的性价比很低。

## 6. 建议的下一步（按性价比排序）

1. **把"覆盖度/讨论热度"本身做成正式因子**（而非情绪分）。它是目前唯一有正向经济含义的信号，
   对应书 3.4.7 改进方向 2）"关注度因子"。需要做的是：控制掉市值/流动性/动量后，看讨论热度突增是否还有 alpha。
2. **把 `factor_clean_alpha` 反向使用**，或作为动量策略的负面过滤器（高情绪分=拥挤=减仓）。
   四子期不变号，这是当前最可靠的发现。
3. **重跑 walkforward，把票池限制为"被讨论过的股票"，基准也换成同一票池等权**，
   这样才能分清"选池收益"和"选股收益"。此前 Route A 夏普 2.20 需要按这个口径重算。
4. 暂缓全量 LLM 重抽，直到 1~3 确认哪一类信号值得投入。

- 「被星球研报/事件覆盖」这一信号，在**剔除行业、市值、流动性、动量后仍呈稳定正向**
  （γ 全为正，6 个组合方向一致；细分行业匹配残差 +7.4%, t=+2.40；十个市值组价差全正）
- 效应**在中小市值更强**，说明它更像"研究覆盖带来的信息发现"而非"大票动量"

**不存在什么**：
- **统计显著性不足**：非重叠 t 最高仅 1.57，2025H1 符号为负
- **情绪评分的方向性选股能力**：三轮检验均否
- **20 个月 = 约 20 个独立月度观测**，样本量本质上不够支撑 t>2 的稳定结论

**按书 5.1.5-⑤ 安全边际原则**：一个非重叠 t≈1.5、子期有反号的信号，实盘期望值应打到接近零。
**结论：不投实盘。** 但这个信号**不应被判死**——它是三轮下来唯一方向稳定、且经济逻辑清晰的发现。

## 6. 如果要继续，唯一有意义的动作

**扩大样本，而不是换模型/换算法。**

现状：20 个月 ≈ 20 个独立观测。要把 t 从 1.5 推到 2.0，在效应量不变的前提下需要约 **2 倍样本**，
即再补 20 个月历史（2023-2024）。而原始星球数据已抓 56,532 条，
但 LLM 只抽取了其中约 12,000 条对应的部分 —— **剩余部分才是提升统计功效的关键，不是换 prompt 或换模型。**

**明确不建议**：
- 再做情绪评分方向性实验（三轮否证）
- 在当前样本上继续调参 —— 20 个独立观测下任何调参都是过拟合
