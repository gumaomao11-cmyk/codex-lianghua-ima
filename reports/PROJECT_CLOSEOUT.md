## 1. 因子档案

### 1.1 已证实为真的因子

**因子名称**：`Planet_Research_Coverage_Alpha`（星球研报关注度因子）

| 属性 | 内容 |
|---|---|
| 定义 | 个股是否被星球研报/单一事件覆盖（0/1 哑变量，或 60 交易日滚动覆盖） |
| **生效域** | **美股中小盘（市值十分位 1~5）** |
| **失效域** | Megacap 大盘（十分位 9：+19.3%, t=1.21，最弱） |
| 效应量 | 日均价差 **9.11 bps**，年化 **+23.0%**，信息比 **+0.93** |
| 剔除行业后 | 细分行业匹配残差 **+7.4%（t=+2.40）** |
| 剔除市值后 | 规模匹配残差 **+17.6%（t=+2.56）**，几乎未衰减 |
| FM 回归 γ | 6 个组合**全为正**（+6.8% ~ +16.0%），方向一致 |
| **致命弱点** | **非重叠 t 最高 1.57；2025H1 符号为负** |

**最强单点证据**：市值十分位 1 组内，被覆盖 vs 未被覆盖价差 **+54.0%（t=3.24）**；
十个市值组价差**全部为正**，且小市值组最强 —— 排除了"大票动量代理"解释。

## 2. 止损决策的量化依据（功效分析）

### 2.1 "20 个独立观测"只适用于 21 日期限

我需要纠正一个此前双方沿用的表述。独立观测数取决于持有期：

| 期限 | 交易日数 | **独立观测数** |
|---|---|---|
| ret_1d | 411 | **411** |
| ret_5d | 407 | 81 |
| ret_21d | 391 | **18** |

**"20 个独立月度观测"仅适用于 21 日期限。**日频口径下已有 411 个独立观测，
而 t 仍只有 1.19~1.57。**这说明约束不只是自由度，效应量相对噪声本身就偏小。**

### 2.2 精确的功效缺口

日频覆盖价差：均值 9.11 bps，标准差 155.6 bps，n=411，t=1.19。

| 路径 | 需要什么 | 可行性 |
|---|---|---|
| **加长时间** | n 需 ×2.72 → **1,119 个交易日 = 4.4 年**（现有 1.6 年） | **不可行**：源数据 2025-01 起始，物理上无 23-24 年数据 |
| **提高效应量** | 效应需 ×1.65（+23.0% → +37.9%/年） | **无证据支持**：更密集抽取能降因子噪声，但没有理由相信能把效应放大 1.65 倍 |

**核准结论**：**用户的止损判断成立。** 补抽剩余数据无法突破 t=1.96。

### 2.3 剩余 79% 数据为什么不值得抽

| 指标 | 值 |
|---|---|
| 原始帖子 | 56,532 |
| 已送 LLM | 11,946（**21%**） |
| 未处理 | **44,586（79%）** |
| **未处理数据的时间分布** | **全部落在同样的 2025-01 ~ 2026-08** |

**关键**：这 79% 只能提升**截面密度**（每日覆盖更多标的），**无法增加时间序列自由度**。
按 §2.2，时间轴不延长则 t 无法过线。抽取成本约 44,586 次 LLM 调用，
预期收益是"因子噪声下降"，但无法量化其能否补足 1.65 倍效应缺口。

**因此不建议投入。**

## 3. 三轮审计中修正的五个错误（供未来复盘）

| # | 我的错误结论 | 真实情况 | 根因 |
|---|---|---|---|
| 1 | Route A 夏普 2.20 / alpha 25% / IR 1.72 | 同池基准下 alpha +7.5%（t=0.43） | 基准用全票池，策略只在讨论池选股 |
| 2 | 情绪是稳定反向指标（单调性 -0.90） | 修复后 +0.70 | **无限期 ffill**：88.1% 因子值是陈旧复制，单值最长持续 399 天 |
| 3 | 文本只覆盖 4 个月 | 实际 **20 个月、12,637 事件** | 只读了一个缓存文件；旧 events parquet 被 42 支硬编码白名单脚本覆盖 |
| 4 | 票池 39 支 | 实际 **175 支** | 旧脚本硬编码白名单丢弃 4,006 个事件 |
| 5 | 票池效应完全是行业 beta（残差 -1.6%, t=-0.24） | 真实行业下残差 **+7.4%（t=+2.40）** | **行业映射只覆盖 26%**，74% 的票被塞进 OTHER 桶 |

**三个可复用的教训**：
1. **任何"因子跨度远超数据源跨度"的现象，先查 ffill**。
2. **归因基准的口径必须与策略票池一致**，否则把 beta 当 alpha。
3. **控制变量的数据质量决定归因可信度**：`turnover_20d` 曾是均价占位符（corr(close)=+0.965），
   行业映射曾只覆盖 26% —— 两者都让结论反号。

## 5. 未来复用指南（拿到新数据集时的 5 分钟判决流程）

### 5.1 前置条件检查（必做，否则结论不可信）

```
1. 因子跨度 <= 事件数据跨度？        -> 否则有 ffill 污染
2. 新信息占比 > 90%？                -> scripts/23_verify_fixes.py
3. 控制变量都是真实值？              -> 检查 corr(close, turnover) 应为负
4. 行业映射覆盖率 > 95%？            -> scripts/26_real_sector_map.py
```

### 5.2 判决流水线（按顺序跑）

| 步骤 | 脚本 | 通过标准 |
|---|---|---|
| 1. 重建事件 | `21_rebuild_events.py` | 覆盖标的数、时间跨度符合预期 |
| 2. 对齐+衰减 | `22_rebuild_aligned_v2.py` | 新信息占比 >90% |
| 3. 缺陷验证 | `23_verify_fixes.py` | 单值持续 <= horizon |
| 4. 分位数+多空 | `06_quantile_analysis.py` | 单调性 \|>0.6\|，**非重叠 t > 1.96** |
| 5. 同池归因 | `27_real_sector_attrib.py` | 细分行业匹配残差 t > 1.96 |
| 6. 市值代理排查 | `28_coverage_vs_size.py` | 规模匹配后残差不衰减 |
| 7. **最终裁决** | `29_coverage_fm.py` | **FM γ 非重叠 t > 1.96 且子期不反号** |
| 8. 功效分析 | `30_power_analysis.py` | 若 t<1.96，算清需多少数据才够 |

**放弃标准**（任一触发即止损）：
- 非重叠 t < 1.64
- 四个子期中有反号
- 功效分析显示所需数据量不可得

### 5.3 值得优先尝试的新数据方向

基于本次唯一的真发现（**中小盘研究覆盖有效，大盘无效**）：

1. **中小盘为主的信息源**优先于大盘财经媒体（本次 megacap 组 t=1.21 最弱）
2. **时间跨度 >= 4 年**是硬门槛（§2.2 算出需 4.4 年）
3. **"是否被覆盖"比"情绪评分"更有价值** —— 前者三轮方向稳定，后者三轮证否

## 7. 结案陈述

本项目未找到可投实盘的 alpha，但完成了三件有价值的事：

1. **否证了一个直觉上很吸引人的假设**（LLM 情绪评分能选股），并经三轮独立检验确认。
2. **发现了一个方向稳定的真信号**（中小盘研究覆盖度），并精确量化了它距离可用还差多少
   （需 4.4 年数据 或 效应 ×1.65），从而把"要不要继续投入"变成了一个有答案的问题。
3. **建成了一套机构级审计流水线**，把"回测夏普 2.20"这类数字从 4 个不同角度拆解到
   "beta / 票池 / 行业 / 市值 / 静态标的效应 / 真 alpha"，并在过程中自查出 5 个错误结论。

**最有价值的产出不是因子，是那 5 个被自己推翻的结论 —— 它们对应的 4 个基础设施缺陷已全部修复，
未来任何新数据集都不会再踩同样的坑。**
