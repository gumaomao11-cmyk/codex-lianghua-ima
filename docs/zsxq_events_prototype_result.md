- 本次事件集中在 2026-08-11~23，晚于价格数据(截至08-21)的最后一个调仓(07-31)。
- 因此回测显示动量+事件 与纯动量 **完全一致**：IS 1.02 / OOS 0.37 即纯动量本身的分段，不是"加入因子后的有效提升"。
- 现阶段只能确认**管线可用、抽取质量达标**，尚不能得出"提升夏普"的结论。
