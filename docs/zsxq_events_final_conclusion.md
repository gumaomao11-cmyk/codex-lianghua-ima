## 验证了两层假设，结论明确

### 算法优化(4种) -> 不行
异常关注度/强信号过滤/log变换/平衡加权，全部 0.52-0.57，不如纯动量

### LLM Prompt优化(严格版) -> 也不行
严格 prompt 只抽评级变动/目标价调整，砍掉71%的positive噪音
但286篇只抽出8条有效美股事件(2.8%)，太少无法影响回测

### 根本原因: 数据源
浑水调研Plus 主要是 A股/港股/韩股收盘点评和宏观分析
真正涉及美股评级变动的信号极少(8条/286篇=2.8%)
